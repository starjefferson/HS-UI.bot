HS-BOT — SETUP AND OPERATING GUIDE
==================================

OVERVIEW
--------
This is a Node.js Head & Shoulders trading bot for a MetaTrader account
connected through MetaApi. It fetches market data, checks trend alignment and
pattern rules, then may submit orders to the connected account.

There is no web UI or dashboard. Monitor account activity in MT5 and monitor
runtime output with the terminal or PM2 logs.


REQUIREMENTS AND CONFIGURATION
------------------------------
1. Install Node.js 20 or later and npm.
2. Create or edit `.env.local` in the repository root:

     METAAPI_TOKEN=your_metaapi_token
     METAAPI_ACCOUNT_ID=your_metatrader_account_id

   Optional settings:

     BROKER_SYMBOL_SUFFIX=r
     RISK_PERCENT=1
     MIN_RR=2.5
     BREAKOUT_BUFFER_PIPS=2

   Set `BROKER_SYMBOL_SUFFIX` only if the symbols in the MetaTrader account
   actually use that suffix. Risk overrides are validated at startup; the
   configured maximum risk percentage and minimum RR are defined in
   `config.js` and `index.js`.

3. Confirm the MetaApi account ID is the intended HotForex/MetaTrader account
   and that it is deployed and connected before enabling live trading.
4. Install dependencies:

     npm install


RUN THE BOT
-----------
Run in the foreground:

     npm start

Run continuously with PM2:

     npm install -g pm2
     npm run start:prod
     pm2 save
     pm2 startup

Follow the instructions printed by `pm2 startup` on the host.

Useful commands:

     pm2 list
     npm run logs
     npm run monitor
     pm2 restart hs-bot
     pm2 stop hs-bot

The PM2 configuration starts only the bot. To remove a dashboard process left
over from an older deployment, run `pm2 delete hs-ui` on that host.


TRADING AND MONITORING
---------------------
- The configured symbols, risk cap, and default breakout buffer are in
  `config.js`.
- `RISK_PERCENT`, `MIN_RR`, and `BREAKOUT_BUFFER_PIPS` can be overridden through
  the environment, subject to startup validation.
- Trend alignment is checked on W1, D1, H4, and H1. Structural patterns are
  checked on D1, H4, and H1. When multiple same-direction patterns qualify,
  the smallest timeframe supplies the right-shoulder stop and the largest
  supplies the measured-move target; the first neckline breakout triggers the
  trade. Conflicting directions are rejected.
- H1 structures use M15 candles for breakout confirmation; D1/H4 structures
  use H1 candles.
- Review scan output and verify the selected account, symbols, and position
  sizing before running with live funds. Trading involves financial risk.

Trade records are written to `history.json`. PM2 logs are written under
`logs/` as configured in `pm2.ecosystem.config.cjs`.


SECURITY
--------
- Do not commit or share `.env.local`; it is excluded by `.gitignore`.
- Restrict access to MetaApi credentials and the VPS running the bot.
- Use a demo account to validate configuration and execution behavior before
  connecting a live account.
