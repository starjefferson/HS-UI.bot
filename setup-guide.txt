================================================================================
      DERIV DIRECT API HEAD & SHOULDERS TRADING BOT - SETUP & OPERATING MANUAL
================================================================================

1. OVERVIEW
--------------------------------------------------------------------------------
This project is an autonomous Head & Shoulders algorithmic trading bot that
connects DIRECTLY to Deriv's WebSocket API (wss://ws.derivws.com).

It requires NO MetaTrader 5 (MT5), NO Expert Advisors (EA), and NO desktop
trading terminals. Everything runs in Node.js and communicates with Deriv
via live WebSocket connections.

It runs continuously, scanning market candles, enforcing top-down trend
alignment, detecting structural H&S patterns, and executing trades directly
to your Deriv account.

Architecture:
  - Bot Engine   → index.js       (standalone Node.js process, hourly loop)
  - Dashboard UI → app/           (Next.js + React, live data from history.json)
  - Both processes managed by PM2 on your Linux VPS.


2. DERIV ACCOUNT SETUP & API TOKEN GENERATION
--------------------------------------------------------------------------------
Step 1: Create an Account
  - Go to https://deriv.com and create a Real or Demo account.

Step 2: Generate Your API Token (DO NOT use developers.deriv.com PAT!)
  - Log in to your Deriv trading account at https://app.deriv.com
  - Go to: Account Settings → Security & Limits → API Token
    (Direct link: https://app.deriv.com/account/api-token)
  - Choose a name (e.g. "HSBot")
  - Tick ALL required scopes:
      [x] Read
      [x] Trade
      [x] Payments
      [x] Trading information
      [x] Admin
  - Click "Create" and copy the token.
  - IMPORTANT: The token must look like a standard ~15 character code (e.g. "a1b2c3d4e5f6").
    Do NOT use a token starting with "pat_" from developers.deriv.com. Deriv's
    WebSocket API will reject "pat_" tokens with "InvalidToken".

Step 3: App ID Configuration
  - Set DERIV_APP_ID=1089 in your .env.local file.
  - 1089 is Deriv's official public WebSocket App ID and works for both Demo and Real accounts.
  - Deriv WebSocket API requires a NUMERIC App ID. Do NOT use alphanumeric IDs from
    developers.deriv.com app registration.

Step 4: Test Your Connection
  - Run the diagnostic tool:
      npm run test:deriv
  - If everything is configured correctly, it will verify authorization, print your
    account balance, and test the EURUSD market candle feed.


3. LOCAL ENVIRONMENT CONFIGURATION
--------------------------------------------------------------------------------
Step 1: Install Dependencies
  Open your project terminal and run:
    npm install

Step 2: Configure Environment Variables
  Edit the file named `.env.local` in the root folder of your project:

    DERIV_APP_ID=1089
    DERIV_API_TOKEN=your_deriv_api_token_here

    # Risk & Strategy Configuration
    RISK_PERCENT=5.0
    MIN_RR=2.5
    MAX_RR=3.0
    POLL_INTERVAL_SECONDS=60

  Notes:
    - Replace `your_deriv_api_token_here` with your real Deriv API token.
    - Set RISK_PERCENT to the percentage of balance to stake per trade (default: 5%).
    - MIN_RR and MAX_RR define the acceptable Risk-to-Reward range (default: 2.5–3.0).
    - The bot also enforces weekly trade limits defined in config.js (maxTradesPerWeek).


4. RUNNING THE BOT
--------------------------------------------------------------------------------
Development mode (both bot + UI together):
  npm run dev

Bot engine only:
  npm run dev:server

Dashboard UI only:
  npm run dev:ui

To run in 24/7 background mode on Linux (Recommended):
  Step 1: Build the Next.js UI first:
    npm run build

  Step 2: Install PM2 globally:
    npm install -g pm2

  Step 3: Start both processes with PM2:
    npm run start:prod

  Step 4: Save the process list for auto-restart on reboot:
    pm2 save
    pm2 startup
    (Follow the printed instructions to enable the startup script.)

  Useful PM2 commands:
    pm2 list              → List running processes and status
    npm run logs          → Stream live logs (bot + UI)
    npm run monitor       → Open PM2 monitoring dashboard
    pm2 restart hs-bot    → Restart just the trading bot
    pm2 restart hs-ui     → Restart just the dashboard UI
    pm2 stop all          → Stop all processes


5. CLOUD / 24/7 HOSTING OPTIONS
--------------------------------------------------------------------------------
This bot runs on any Linux environment. No Windows required.

  Option A: Linux VPS (DigitalOcean, Vultr, Linode, AWS EC2) - $4-6/month
    1. SSH into your Linux instance.
    2. Install Node.js v20+ and Git:
         curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
         sudo apt-get install -y nodejs git
    3. Clone your repository:
         git clone <your-repo-url> && cd HS-UI.bot
    4. Install dependencies:
         npm install
    5. Create .env.local with your real credentials:
         nano .env.local
    6. Build the UI:
         npm run build
    7. Start via PM2:
         npm run start:prod
         pm2 save && pm2 startup

  Option B: Cloud App Hosting (Render.com / Railway.app)
    1. Push your repository to GitHub.
       (Ensure .env.local is NOT committed — it is already in .gitignore.)
    2. Create a Background Worker service connected to your repository.
       Set the start command to: node index.js
    3. Create a separate Web Service for the UI.
       Set the build command to: npm run build
       Set the start command to: npm start
    4. Add your environment variables in the cloud provider's settings dashboard.


6. LOGS & FILE MEMORY
--------------------------------------------------------------------------------
- `history.json`: Records all executed trades. Used by the Pattern Fingerprinting
  Guard to prevent re-entering identical setups across scan cycles.
- `logs/hs-bot-out.log`: PM2 stdout log for the trading bot.
- `logs/hs-bot-error.log`: PM2 error log for the trading bot.
- `logs/hs-ui-out.log`: PM2 stdout log for the dashboard UI.
- Live Console Output: Displays real-time 3/4 SMA Trend Scores, active biases,
  pattern detection logs, canTrade() risk checks, and Deriv order responses.


7. IMPORTANT SECURITY NOTES
--------------------------------------------------------------------------------

- NEVER share your Deriv API token publicly.
- Start with a Demo account to verify the bot is working before switching to live.
- The bot will use RISK_PERCENT of your balance per trade. Start conservatively.
