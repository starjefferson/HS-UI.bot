HS-BOT — RUNTIME FLOW
=====================

This project is a Node.js trading bot that connects to a MetaTrader account
through MetaApi. It has no web server, dashboard, or browser UI.

STARTUP
-------
- `index.js` loads `.env.local` (or `.env`), validates risk-related settings,
  and starts the initial trading scan.
- `src/metaApi.js` creates and shares the MetaApi account and RPC connection.
  Connection initialization and reconnects are serialized so simultaneous
  candle fetches do not replace one another's connection.
- The initial scan and scheduled hourly scans report failures and continue
  scheduling the next cycle.

SCAN CYCLE
----------
1. Read account equity and open positions.
2. For each configured symbol, fetch W1, D1, H4, H1, and M15 candles.
3. Require agreement from at least three of W1/D1/H4/H1 for a directional bias.
4. Detect H&S structures on D1, H4, and H1. Reject conflicting directions.
   If multiple same-direction structures qualify, use D1 levels first, then H4,
   then H1; the other structures provide context.
5. Confirm the breakout on H1 for D1/H4 structures or M15 for H1 structures.
6. Apply pattern fingerprinting, risk/reward checks, trade-frequency and
   correlation guards, plus the gold-specific guards before order submission.
7. Record successfully opened trades in `history.json`.

OPERATIONS
----------
- Start directly with `npm start`.
- Start under PM2 with `npm run start:prod`.
- View bot logs with `npm run logs`; process configuration is in
  `pm2.ecosystem.config.cjs`.
- Configure MetaApi credentials in `.env.local` and keep that file private.
- See `setup-guide.txt` for installation, environment settings, and deployment.
